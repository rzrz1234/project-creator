# Windows 打包规范

已验证版本：v1.0.3，Windows 10 22H2 x64。

- Python 3.12.11、PySide6 6.12.0、PyInstaller 6.22.3。
- 使用独立构建虚拟环境，清理 conda、pixi、rattler 和 Library/bin 的 PATH。
- 只生成 onedir：ProjectCreator.exe 与 _internal；不生成 onefile。
- spec 在 Analysis 后过滤 ICU，构建脚本再次扫描；产物禁止出现 icu*.dll。
- 不从第三方环境复制 ICU，不预加载 ICU，使用系统 ICU。
- 输出放到仓库上一级的同名“_打包”文件夹。

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\packaging\build.ps1
```

此脚本生成目录版程序。安装器使用 Inno Setup 打包整个目录，快捷方式指向 ProjectCreator.exe。必须先在普通 Windows 环境实际验证主窗口、项目创建、无 QtCore 异常，再发布安装器。
